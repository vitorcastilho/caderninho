Tokens e regras

Referência rápida para implementação. Veja a spec completa em proto-18-tela-transacoes-spec.md.

Cards de resumo
  • 3 cards: Saídas / Entradas / Transferências
  • Cor do label: negative / positive-text / info-text
  • Cor do valor: foreground / positive-text / muted-foreground
  • Ícone do label: trending-down / trending-up / arrow-left-right
  • Padding: 14×16px · border-radius: 10px
  • Backend: SUM agrupado por tipo no período filtrado
  • Mobile: 3 cards lado a lado com fonte/padding reduzidos
Filtros (Abordagem 3)
  • Linha 1: Busca · Tipo (segmented) · Mês (pílula) · Filtros (botão)
  • Tipo: Tudo / Saídas / Entradas / Transferências
  • Tipo mobile: "Transf." abreviado
  • Mês: pílula clicável que abre dropdown
  • Filtros (botão): abre side sheet com Categoria + Método
  • Badge (N): contador de filtros ativos no botão
  • Chips ativos: abaixo da linha, removíveis (✕) + "Limpar tudo"
Side Sheet de filtros
  • Largura desktop: 360px · mobile: 100vw
  • Conteúdo: só Categoria + Método
  • Categorias: checkbox + emoji + nome
  • Métodos: checkbox + BankLogo (sm) + nome
  • Footer: Limpar (ghost) + Aplicar (primary)
  • Padrão: reusa estilo do EditExpenseSheet/ConfirmDeleteTransactionDialog
